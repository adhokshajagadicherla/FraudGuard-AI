# 🛡️ Credit Card Fraud Detection Using Machine Learning

> **College Project** — B.Tech CSE (Big Data Analytics), 3rd Year  
> SRM Institute of Science and Technology, Tiruchirappalli

A professional, full-stack fraud detection system built with Python and Streamlit.  
It trains two ML classifiers on credit card transaction data and exposes a real-time  
prediction dashboard with rich visualisations.

---

## ✨ Features

| Feature | Details |
|---|---|
| **Data Pipeline** | Loads real Kaggle dataset or auto-generates synthetic data |
| **No Data Leakage** | Scaler fitted on training set only; stratified 80/20 split |
| **Two Models** | Logistic Regression · Random Forest (both with `class_weight='balanced'`) |
| **Rich Metrics** | Precision · Recall · F1 · PR-AUC · ROC-AUC · Confusion Matrix |
| **Interactive Dashboard** | 5-page Streamlit app with Plotly charts |
| **Real-time Predictor** | Score any transaction instantly with probability gauges |
| **Cloud-ready** | Deployed on Streamlit Community Cloud |

## 🚀 Run Locally

### 1 — Prerequisites

- Python 3.10 or higher
- pip

### 2 — Install dependencies

```bash
pip install -r requirements.txt
```

### 3 — (Optional) Download the real dataset

Download **creditcard.csv** from Kaggle and place it at `data/creditcard.csv`:

```
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
```

If the file is absent the training script generates realistic synthetic data automatically.

### 4 — Train the models

```bash
python train_model.py
```

This creates `models/` with the trained `.pkl` files and `data/sample_data.csv`.

### 5 — Launch the dashboard

```bash
streamlit run app.py
```

Open **http://localhost:8501** in your browser.

## ☁️ Deploy to Streamlit Community Cloud

1. **Push the repository to GitHub** (make sure `models/` and `data/sample_data.csv` are committed — they are NOT in `.gitignore`).

2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.

3. Select your GitHub repo, branch (`main`), and set **Main file path** to `app.py`.

4. Click **Deploy**.

> **Note:** The full `creditcard.csv` is excluded from Git (150 MB). The app works on  
> Streamlit Cloud using the pre-trained models and built-in sample data.

## 🧪 Dataset

| Property | Value |
|---|---|
| Source | [Kaggle — mlg-ulb/creditcardfraud](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) |
| Transactions | 284,807 |
| Fraud cases | 492 (0.172 %) |
| Features | V1–V28 (PCA), Time, Amount, Class |

All V1–V28 features are **PCA-transformed** principal components — they contain no  
readable cardholder information.

---

## ⚙️ Methodology

### Preprocessing
- `StandardScaler` applied **only** to `Time` and `Amount` (V1–V28 are already normalised via PCA)
- Scaler is **fit on training data only** → prevents data leakage
- `train_test_split(stratify=y)` → preserves fraud ratio in both splits

### Class Imbalance
- `class_weight='balanced'` in both classifiers
- **Precision-Recall AUC** used as the primary metric (accuracy is misleading for ~0.17% fraud rate)

### Models

| Model | Parameters |
|---|---|
| Logistic Regression | `max_iter=1000, solver=lbfgs, class_weight=balanced` |
| Random Forest | `n_estimators=150, max_depth=14, class_weight=balanced` |
